# Landing copy audit

This audit is generated from the cold landing page’s visible copy units. It
includes the skip link, header, first screen, sample preview, explanatory
sections, privacy section, and footer. Multi-sentence units have one row per
sentence. The Playwright test `the committed copy audit matches every current
landing copy unit and sentence` compares this table exactly with the rendered
page and checks every count.

Counts treat punctuation, paths, symbols, and hyphenated terms as part of one
space-separated word. No item exceeds 22 words. `pass` means the wording is
plain, uses the product’s established terms, and has no banned marketing word.
